# Требования к фото для YouTube канала "Clásicos en Corto"

## 📁 Структура папок
- `logo/` - Логотип канала (для аватара)
- `thumbnail/` - Превью для видео
- `watermark/` - Водяной знак для видео

## 🎨 Требования к изображениям

### 1. Логотип канала (Аватар)
- **Размер:** 800x800 пикселей
- **Формат:** PNG с прозрачным фоном
- **Содержание:** Иконка книги + текст "Clásicos en Corto"
- **Стиль:** Минималистичный, читаемый на маленьком размере
- **Цвета:** Тёмно-синий/фиолетовый фон, белый текст

### 2. Баннер канала
- **Размер:** 2560x1440 пикселей (16:9)
- **Безопасная зона:** 1546x423 пикселей (центр)
- **Формат:** PNG или JPG
- **Содержание:** 
  - Название канала: "Clásicos en Corto"
  - Подзаголовок: "Literatura Rusa en Español"
  - Атмосфера: Книги, русская эстетика, классика
- **Стиль:** Элегантный, литературный, тёмные тона

### 3. Превью для видео (Thumbnails)
- **Размер:** 1280x720 пикселей (16:9)
- **Формат:** JPG или PNG
- **Стиль:** Яркий, контрастный, с крупным текстом
- **Элементы:**
  - Крупный заголовок (3-5 слов)
  - Изображение автора/книги
  - Эмоциональный элемент (вопрос, восклицание)
  - Логотип канала (угол)

### 4. Водяной знак
- **Размер:** 150x150 пикселей
- **Формат:** PNG с прозрачным фоном
- **Содержание:** Логотип канала
- **Позиция:** Правый нижний угол видео

## 🎯 Цветовая палитра
- **Основной цвет:** #1a1a2e (тёмно-синий)
- **Акцентный цвет:** #e94560 (красный/розовый)
- **Текст:** #ffffff (белый)
- **Фон:** #16213e (тёмно-фиолетовый)

## 📌 Рекомендации по дизайну
1. Использовать шрифты с засечками (Serif) для литературной атмосферы
2. Добавить элементы русской культуры (узоры, орнаменты)
3. Соблюдать единый стиль во всех изображениях
4. Текст должен быть читаем на маленьких экранах мобильных устройств
