# 🎨 Промпты для Gemini (Google AI) для генерации изображений

## 📋 Инструкция по использованию:

1. Откройте Google Gemini: https://gemini.google.com/
2. Скопируйте промпт
3. Вставьте в Gemini
4. Сгенерируйте изображение
5. Сохраните результат

---

## 1. Баннер канала (2560x1440 пикселей)

### Промпт для Gemini:

```
Create a YouTube channel banner for "Clásicos en Corto" - a channel about Russian literature in Spanish.

Dimensions: 2560x1440 pixels

Design requirements:
- Dark elegant background with gradient from dark blue (#1a1a2e) to dark purple (#16213e)
- Center the main text: "Clásicos en Corto" in large, elegant serif font (Georgia style)
- Below main text: "Literatura Rusa en Español" in smaller gold color (#f59e0b)
- Add decorative elements: open books, Russian literary atmosphere, subtle circles
- Include author names: "Dostoyevski • Tolstói • Bulgákov" in the middle section
- Add a call-to-action button: "Suscríbete Ahora" in red/crimson color (#e94560)
- Use color scheme: dark blue, dark purple, crimson red accents, gold highlights
- Professional, cinematic, literary aesthetic
- Important text should be in the center safe zone (1546x423 pixels)
- Add subtle book emoji or book icons as decorative background elements
- Make it visually striking but readable
- Style: elegant, sophisticated, academic but modern
```

## 🎯 Советы по использованию Gemini:

1. **Генерируйте несколько вариантов** - выберите лучший
2. **Уточняйте детали** - если результат не идеален, добавьте корректировки
3. **Экспериментируйте со стилями** - попробуйте разные описания
4. **Проверяйте размер** - убедитесь, что изображение соответствует требованиям
5. **Сохраняйте в PNG** - для лучшего качества

---

## 📊 Требования к размерам файлов:

- **Баннер:** Максимум 6 МБ
- **Фото профиля:** Максимум 4 МБ
- **Логотип:** Максимум 4 МБ
- **Водяной знак:** Максимум 1 МБ
- **Превью:** Рекомендуется 2 МБ или меньше

---

## 🔄 Если результат не идеален:

**Добавьте в промпт:**
- "More minimalist" (более минималистичный)
- "More dramatic" (более драматичный)
- "More elegant" (более элегантный)
- "Higher contrast" (более высокий контраст)
- "Less cluttered" (менее загроможденный)
- "More professional" (более профессиональный)

**Укажите конкретные элементы:**
- "Make the text larger" (сделайте текст крупнее)
- "Add more gold accents" (добавьте больше золотых акцентов)
- "Make the background darker" (сделайте фон темнее)
- "Add subtle shadows" (добавьте мягкие тени)
